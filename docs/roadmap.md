# 路线图

当前版本 `0.1.0`：写入、覆盖、混合召回、MCP + REST、面板、限流。

## v0.2 — 让记忆更「聪明」

- [ ] **对话批量摄入**：`POST /v1/ingest` 接受原始对话，异步提炼成 L1 原子（Queues + Workers AI）
- [ ] **语义去重**：写入前查最近邻，相似度 > 0.92 则合并而不是新增
- [ ] **冲突提示**：同 `key` 但内容矛盾时，标记需要人工确认，而不是静默覆盖

## v0.3 — 让记忆更「耐用」

- [ ] **冷热分层**：90 天前的 `l1` 归档到 R2，D1 只留摘要，Vectorize 只索引热数据
- [ ] **导出 / 导入**：`GET /v1/export` 输出 JSON，支持迁移到其他实例
- [ ] **容量告警**：接近 Vectorize 免费额度时在面板提示

## v0.4 — 让记忆更「可管」

- [ ] **多用户 ACL**：`private` / `shared` 两种可见性
- [ ] **审计日志**：谁在什么时候写入/删除了什么
- [ ] **面板增强**：按 key 分组、时间线视图、批量清理

## 明确不做

- 团队资产化（Skill 版本、Wiki、CodeGraph）——那是 TencentDB Agent Memory 的领域
- 多租户计费与配额
- 自建向量索引（除非 Vectorize 额度成为真实瓶颈）
